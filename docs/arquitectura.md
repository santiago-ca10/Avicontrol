#  Arquitectura del Sistema

El sistema Avicontrol sigue una arquitectura cliente-servidor:

##  Frontend
- React.js
- Interfaz de usuario para gestión de datos

##  Backend
- Node.js con Express
- API REST para manejar la lógica del sistema

##  Base de Datos
- MySQL
- Almacenamiento persistente de la información

##  Comunicación
- HTTP (JSON)

##  Patrón
- MVC (Modelo - Vista - Controlador)
