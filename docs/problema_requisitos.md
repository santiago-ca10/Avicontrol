# 🐓 Problema

En muchas granjas avícolas, el control de la producción de huevos se realiza de forma manual o no se lleva un registro adecuado. Esto genera dificultades como:

- Falta de seguimiento individual de cada gallina.
- Desconocimiento de la producción diaria y acumulada.
- Dificultad para identificar gallinas poco productivas.
- Pérdida de información histórica.

#  Objetivo General

Desarrollar una aplicación web que permita gestionar y monitorear la producción de huevos en una granja avícola.

#  Objetivos Específicos

- Registrar gallinas con sus características.
- Registrar la producción diaria de huevos.
- Consultar el historial de producción por gallina.
- Analizar la producción total.

#  Alcance

El sistema permitirá realizar operaciones CRUD sobre gallinas y registros de producción, además de visualizar la información de manera organizada en una interfaz web.
