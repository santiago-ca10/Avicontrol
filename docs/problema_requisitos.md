# 🐓 Problema

En muchas granjas avícolas, el control de la producción de huevos se realiza de forma manual o no se lleva un registro adecuado. Esto genera dificultades como:

- Falta de seguimiento individual de cada gallina.
- Desconocimiento de la producción diaria y acumulada.
- Dificultad para identificar gallinas poco productivas.
- Pérdida de información histórica.
- Ineficiencia en la toma de decisiones para mejorar la producción.

# Objetivo General

Desarrollar una aplicación web que permita gestionar y monitorear la producción de huevos en una granja avícola, con registro de gallinas y producción diaria.

# Objetivos Específicos

- Registrar gallinas con sus características básicas.
- Registrar la producción diaria de huevos por gallina.
- Consultar el historial de producción individual.
- Mostrar métricas de producción acumulada.
- Facilitar el análisis de información para la toma de decisiones.

# Requisitos funcionales

- El usuario puede ver la lista de gallinas.
- El usuario puede registrar una nueva gallina.
- El usuario puede actualizar los datos de una gallina.
- El usuario puede eliminar una gallina.
- El usuario puede registrar la producción de huevos.
- El usuario puede ver los registros de producción.
- El usuario puede consultar la producción total de huevos.

# Requisitos no funcionales

- La aplicación debe ser accesible desde un navegador web moderno.
- El sistema debe responder rápidamente a las consultas de datos.
- La arquitectura debe separar frontend y backend.
- La comunicación debe ser segura y basada en JSON.

# Alcance

El sistema cubre:

- Gestión de gallinas: creación, lectura, actualización y eliminación.
- Registro de producción de huevos: almacenamiento y consulta.
- Visualización de métricas y estadísticas generales.

No incluye:

- Gestión avanzada de usuarios y autenticación.
- Control de inventario de insumos.
- Reportes complejos fuera de las métricas básicas mostradas en el dashboard.
